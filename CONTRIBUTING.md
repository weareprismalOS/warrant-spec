# Contributing to WARRANT

Thank you for your interest in contributing to the WARRANT Open Standard.

## Ways to Contribute

- **Report issues**: Open a GitHub issue for bugs, clarifications, or suggestions
- **Propose changes**: Submit pull requests for improvements
- **Implement tooling**: Build validators, enforcement engines, or other tools
- **Provide feedback**: Share your experience implementing WARRANT

## Contribution Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Submit a pull request

## Style Guidelines

- Specification documents follow IETF Internet-Draft formatting
- JSON Schema follows draft-07 conventions
- All contributions must be compatible with CC BY 4.0 licensing
